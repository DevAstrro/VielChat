SECURITY MODEL

Designed to minimize retained data.

  • Text and files use an encrypted WebRTC data channel.
  • The app server keeps session state in RAM; it does not store chat messages or files.
  • The invitation is a bearer secret. Share it only with the intended person.
  • Compare the connection verification code out-of-band before sensitive use.
  • Websites cannot reliably block screenshots or erase downloaded copies.
  • Hosting providers may retain network logs, and a compromised device can expose content.

This project is not independently audited. Do not use it for high-risk or highly sensitive conversations until a professional security review is complete.
